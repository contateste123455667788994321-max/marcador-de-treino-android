# Marcador de Treino Android

Aplicativo Android do Marcador de Treino. Usa interface https://marcador-de-treino-ckcg.hatchable.site e sensor nativo `TYPE_STEP_COUNTER` para contar passos em segundo plano (após permissão de atividade física).

Build: Github Actions → Gerar APK → artifact `Marcador-de-Treino-Android-APK`. O APK é build de teste, não publicado na Play Store.

O código não contém credenciais; música via players externos e visual depende de conexão com Internet.
